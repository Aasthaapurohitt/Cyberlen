What it does

Real-time scanning

A lightweight content script scrapes the URL, DOM, forms, and scripts on every page load and reports it instantly.

Explainable risk scores

A Random Forest model scores each page, and SHAP turns the top contributing features into plain-English reasons.

Team dashboard

Every scan lands in a shared history with risk trends over time — built for a small security or IT team to review together.

Lightweight extension

No build step, no bundler — a plain Manifest V3 extension that scopes its own permissions to exactly what it needs.

How it works

  1. 1

    Extension scans the page

    The browser extension scrapes URL, DOM, forms, and scripts, then sends them to the backend.

  2. 2

    Express orchestrates

    The Node/Express API saves a pending record in MongoDB, then forwards the payload to the ML service internally.

  3. 3

    The model scores and explains

    A FastAPI service extracts features (domain age, SSL validity, redirects, lexical patterns), scores the page, and uses SHAP to explain the result.

  4. 4

    Result reaches you instantly

    Express relays the score back to the extension popup and stores it for the dashboard — both update in real time.
